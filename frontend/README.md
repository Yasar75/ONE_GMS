# LMS Frontend (React JSX)

## Run locally
```bash
cd learning-management-system/frontend
npm install
npm run dev
```

## Notes
- JSX only (no TypeScript)
- Bootstrap 5.3 layout with fixed Header + Footer
- Desktop/Tablet: left sidebar with pin + collapse
- Mobile: top navbar with hamburger toggle
- Mock auth/dashboard data for now (plug FastAPI later)
